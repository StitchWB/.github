# StitchWB

Universal account manager for AI IDEs and AI providers, plus its plugin ecosystem.

| Repo | What |
|---|---|
| [Stitch-Manager](https://github.com/StitchWB/Stitch-Manager) | Client (app + autoreg engine) — public source of truth |
| [stitch-totp](https://github.com/StitchWB/stitch-totp) · [stitch-mail](https://github.com/StitchWB/stitch-mail) · [stitch-sheets](https://github.com/StitchWB/stitch-sheets) · [stitch-radar](https://github.com/StitchWB/stitch-radar) · [stitch-opencode](https://github.com/StitchWB/stitch-opencode) · [stitch-notebooklm](https://github.com/StitchWB/stitch-notebooklm) · [stitch-cards](https://github.com/StitchWB/stitch-cards) · [stitch-antigravity](https://github.com/StitchWB/stitch-antigravity) | Service plugins (open-core, subprocess JSON-RPC) |
| [stitch-plugin-catalog](https://github.com/StitchWB/stitch-plugin-catalog) | Community data-only plugins (PR review flow) |
| [stitch-plugin-template](https://github.com/StitchWB/stitch-plugin-template) | Service-plugin scaffold for new authors |
| [stitch-ci](https://github.com/StitchWB/stitch-ci) · [stitch-build](https://github.com/StitchWB/stitch-build) | Public CI and compile farms (free minutes) |

The distribution server, signing keys and autoreg methods live in a private hub
and ship as signed packages; see each repo's docs for the public surface.
